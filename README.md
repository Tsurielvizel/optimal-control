# בקרה אופטימלית – סיכומי הרצאות והעמקה

מאגר זה מכיל סיכומים מסודרים, תמלולי לוח והסברים מעמיקים עבור הקורס **בקרה אופטימלית** (הטכניון).

## מבנה המאגר
* [סיכום_לוח_המרצה.md](./סיכום_לוח_המרצה.md) – הקלדה נקייה ומדויקת של לוחות ההרצאה בנוסחאות LaTeX.

* [AGENT_INSTRUCTIONS.md](./AGENT_INSTRUCTIONS.md) – הנחיות לעוזר AI / אג'נט להמשך עדכון המחברות מתמונות חדשות.
